# neuralgames.github.io

Site da Neural Pixel Play no GitHub Pages: política de privacidade dos jogos e `app-ads.txt`.

| Arquivo | Para quê |
|---|---|
| `app-ads.txt` | Autoriza o AdMob a vender os anúncios dos nossos apps. **Precisa ficar na raiz** e o domínio precisa ser o "site do desenvolvedor" na Play Console |
| `mine-empire/privacidade.html` / `privacy.html` | Política do Mine Empire (pt/en), aberta pelo botão nas configurações do jogo |

Ao mudar a política: atualizar a data "Vigente desde" nas duas línguas e conferir se a Segurança de Dados da Play Console continua igual.
